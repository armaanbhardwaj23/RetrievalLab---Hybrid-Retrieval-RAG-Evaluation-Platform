# RetrievalLab

RetrievalLab is a small, inspectable platform for learning how RAG retrieval
systems work and measuring dense, BM25, and hybrid retrieval quality.

The initial milestone will support PDF, Markdown, and TXT ingestion; traceable
chunking; dense, BM25, and Reciprocal Rank Fusion retrieval; grounded answers
with citations; and retrieval evaluation.

No benchmark results are available yet.
